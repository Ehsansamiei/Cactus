# Cactus Runner (Working Title)

A quirky twist on the classic browser dino game. Except this time, you're not running *from* cacti. You **are** the cactus. Jump over dinosaurs, survive as long as possible, and question your life choices along the way.

## Status
This project is **currently under development**. Expect bugs, chaos, and the occasional cactus-related identity crisis.

## Features
- Play as a sentient cactus.
- Jump over dinosaurs like it's totally normal.
- Infinite runner gameplay.
- Work-in-progress mechanics and assets.

## Technologies Used
- **Python**
- **Pygame**

## How to Run
1. Make sure you have Python installed.
2. Install the required libraries:
   ```bash
   pip install pygame
   ```
3. Run the game:
   ```bash
   python main.py
   ```
